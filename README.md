### 💡 Featured Projects

#### 1. 🏗️ Enterprise Data Warehouse & Analytics Engine
- Designed and built a relational data warehouse using **Medallion Architecture** (Bronze raw ingestion, Silver cleansed tables, Gold aggregated analytics dimensional models).
- Engineered automated ETL stored procedures for transforming raw CRM and ERP data into business-ready star schemas.
- **Tech Stack:** `MySQL` `SQL` `ETL Pipelines` `Data Warehousing`

#### 2. 🧠 [NeuroMind – Autism Spectrum Detection](https://github.com/YUKaiser/Autism_Final_Vin)
- Developed a machine learning classification engine using Python and Logistic Regression to evaluate behavioral datasets.
- Deployed an interactive user interface using **Streamlit** for real-time risk assessment and clinical metrics visual analysis.
- **Tech Stack:** `Python` `Scikit-Learn` `Streamlit` `Pandas`

#### 3. 🚕 Uber Trip Analytics & Performance Dashboard
- Formulated an end-to-end 3-page interactive Power BI report analyzing booking volume, trip velocity, revenue yield, and spatial peak hours.
- Executed data wrangling, cleaning, and complex DAX measure creation over dynamic SQL views.
- **Tech Stack:** `Power BI` `DAX` `SQL` `Data Modeling`
